Greens

Phundamental.Greens provides finite-temperature imaginary-frequency propagators as explicit, matrix-valued objects. The module defines fermionic Matsubara axes, exact Lehmann evaluation, normal and Nambu Green functions, noninteracting/Weiss propagators, self-energies, hybridization functions, Dyson reconstruction, high-frequency moments, and symmetry/causality diagnostics.

The abstraction introduced in v0.0.7 is intentionally broader than a solver-specific array of complex numbers: a propagator carries its frequency axis, matrix structure, component labels, and metadata, so Dyson relations and validation can be applied independently of the numerical method that produced it.

Fermionic Matsubara axis

FermionicMatsubaraAxis stores the inverse temperature $\beta$, integer Matsubara indices, and the corresponding complex frequencies

\[i\omega_n=i(2n+1)\pi/\beta.\]

The count constructor FermionicMatsubaraAxis(beta, npositive) stores indices 0:npositive-1. Passing include_negative=true additionally stores the matching negative indices -npositive:-1. An explicit vector of integer indices can also be supplied.

matsubara_frequency(axis, i) returns the real frequency $\omega_n$ for stored entry i; matsubara_index(axis, i) returns the integer index; inverse_temperature returns $\beta$; and axis_temperature(axis; kB=1) returns $T=(k_B\beta)^{-1}$.

Negative frequencies are not required for ordinary positive-frequency calculations, but conjugation, particle–hole, and full Nambu redundancy diagnostics require positive/negative frequency pairs.

Matrix-valued frequency objects

All propagator-like objects derive from AbstractFrequencyMatrix and store an $N\times N\times N_\omega$ complex array. The public concrete types are:

TypeRole
GreenFunctionInteracting propagator $G(z)$.
NonInteractingGreenFunctionNoninteracting or Weiss propagator $G_0(z)$ or $\mathcal G_0(z)$.
SelfEnergyFrequency-dependent self-energy $\Sigma(z)$.
HybridizationFunctionImpurity hybridization $\Delta(z)$.

Constructors accept scalar-frequency vectors, vectors of square matrices, or a rank-three numerical array. Labels identify the matrix components and metadata records provenance such as Lehmann evaluation, Nambu structure, or a Dyson relation.

frequency_axis, frequency_values, component_labels, and matrix_dimension expose the common structure. scalar_frequency_values extracts a copy of the scalar data from a $1\times1$ frequency object and raises an error for a matrix-valued object.

Two objects entering a Dyson or comparison operation must carry compatible axis type, Matsubara indices, inverse temperature, and matrix dimension. The package checks these conditions rather than relying on array shape alone.

Noninteracting Green functions

noninteracting_green constructs $G_0$ from a one-body Hamiltonian and chemical-potential convention. zero_self_energy constructs the structurally compatible zero self-energy used to initialize noninteracting calculations and DMFT iterations.

A noninteracting propagator is typed separately from GreenFunction because the distinction matters in Dyson's equation and in the embedding layer: a Weiss field is an effective noninteracting impurity propagator even though it is generated by an interacting self-consistency loop.

Exact finite-temperature Lehmann representation

For odd-parity operators $A_a$, lehmann_green evaluates the exact finite-temperature Lehmann form

\[G_{ab}(i\omega_n)=\sum_{m,l}\frac{(p_m+p_l)\langle m|A_a|l\rangle\langle l|A_b^\dagger|m\rangle}{i\omega_n+E_m-E_l},\]

where $p_m=e^{-\beta E_m}/Z$. The thermal state must be an ExactGibbsState, and its $\beta$ must match the Matsubara axis.

matsubara_green(state, axis; modes=...) specializes this construction to fermionic annihilation operators. If modes are omitted, all modes of a non-composite FermionAlgebra are included.

A model-level convenience overload solves the model with ExactGibbs at the temperature encoded by the axis before evaluating the Green function:

beta = 16.0
axis = FermionicMatsubaraAxis(beta, 128)
G = matsubara_green(model; axis=axis)

The exact Lehmann implementation is appropriate for finite ED systems. Large interacting systems need another Green-function backend rather than attempting to scale this dense finite-system formula indefinitely.

Nambu indexing

NambuIndex defines the particle–hole ordering

\[\Psi=(c_1,\ldots,c_M,c_1^\dagger,\ldots,c_M^\dagger)^T.\]

nambu_green evaluates

\[\mathcal G(\tau)=-\langle T_\tau\Psi(\tau)\Psi^\dagger(0)\rangle\]

through the same exact Lehmann machinery. nambu_index retrieves the stored Nambu index metadata, while normal_block, anomalous_block, and hole_block expose the corresponding matrix blocks at one stored frequency.

Nambu is deliberately represented as propagator index structure rather than as a Foundation Representation. A Hamiltonian representation describes the state space and operator algebra; Nambu doubling describes how propagator components are arranged.

Note

The v0.0.7 Green-function layer supports Nambu propagators and their symmetry checks, but the validated ED-DMFT implementation is normal-state and does not yet provide superconducting/Nambu impurity self-consistency.

Dyson relations

self_energy(G0, G) evaluates

\[\Sigma(z)=G_0(z)^{-1}-G(z)^{-1}.\]

dyson_green(G0, Sigma) evaluates

\[G(z)=\left[G_0(z)^{-1}-\Sigma(z)\right]^{-1}.\]

The implementation uses factorizations and linear solves frequency by frequency rather than elementwise reciprocal operations. This distinction is essential for matrix-valued propagators.

Dyson operations preserve component labels and propagate Nambu metadata when present.

High-frequency moments

Fermionic Green functions have the asymptotic expansion

\[G(z)=\sum_{k=0}^{\infty}\frac{M_k}{z^{k+1}}.\]

high_frequency_moment estimates the zeroth moment from the largest stored Matsubara frequencies using $M_0\approx\langle zG(z)\rangle$ over the selected tail.

high_frequency_moments fits multiple moments by complex least squares. high_frequency_moment_residual compares a fitted moment with an expected scalar or matrix value, and zeroth_moment_residual tests the canonical fermionic condition $M_0=I$.

High-frequency diagnostics depend on the stored tail. A small axis containing only low Matsubara frequencies is not sufficient for a reliable moment fit even if the Green function itself is otherwise valid.

Causality

For positive fermionic Matsubara frequencies, a causal propagator or self-energy obeys the appropriate negative-semidefinite imaginary-part condition. causality_residual computes the maximum violation of

\[-\operatorname{Im}X(i\omega_n)\succeq0.\]

The diagnostic only uses positive frequencies and raises an error if none are present.

A zero or very small residual supports consistency with causality; it is not by itself a proof that the entire many-body calculation is physically correct.

Matsubara conjugation

If both positive and negative frequencies are stored, matsubara_conjugation_residual checks

\[X(i\omega_n)=X(-i\omega_n)^\dagger.\]

The Matsubara partner of integer index $n$ is -n-1, because fermionic frequencies are odd multiples of $\pi/\beta$.

Particle–hole symmetry

For a scalar frequency object, particle_hole_symmetry_residual(object; center=C) checks

\[[X(i\omega)-C]+[X(-i\omega)-C]=0.\]

For a particle–hole-symmetric Green function, center=0. For a half-filled Hubbard self-energy, the center can be the Hartree value $U/2$.

This diagnostic is used by the ED-DMFT validation layer and helped motivate the exact particle–hole-constrained finite bath introduced in v0.0.7.

Nambu symmetry

anomalous_norm reports the maximum norm of the particle–hole anomalous block over the stored axis. nambu_symmetry_residual checks the full redundancy

\[\mathcal G(i\omega)=-\tau_x\mathcal G(-i\omega)^T\tau_x,\]

where $\tau_x$ exchanges particle and hole blocks.

As with other positive/negative-frequency identities, the axis must contain paired Matsubara indices.

Validation bundle

validate_green_function returns a dictionary containing the core diagnostics applicable to the supplied Green function. It always checks causality and the zeroth high-frequency moment; it adds Matsubara conjugation when paired frequencies are present and Nambu diagnostics when the object carries Nambu metadata.

The v0.0.7 test suite validates the Green layer against exact atomic Hubbard expressions, noninteracting limits, high-frequency sum rules, Nambu indexing and redundancy, causality, and Dyson reconstruction before the objects enter the embedding layer.

Related modules
