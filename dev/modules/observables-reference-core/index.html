Observable API — Descriptors and Correlations

Observable descriptors and results

Main.Phundamental.Observables.RejectBosonZeroModes — Type
RejectBosonZeroModes(; relative_tol=1e-10)

Default finite-temperature policy for mode-native bosonic response. Any quasiparticle energy at or below relative_tol * max(maximum(abs, energies), 1) raises an error because the Bose occupation diverges as the energy approaches zero.

source
Main.Phundamental.Observables.NumberConservingZeroModeProjection — Type
NumberConservingZeroModeProjection(; relative_tol=1e-10)

Explicit number-conserving policy that removes numerically zero-energy quasiparticle modes from mode-native contractions and spectral lines at all temperatures. This represents the projected noncondensate sector used by number-conserving Bogoliubov formulations; use it only when the omitted mode is known to be the condensate/Goldstone direction. Solver-side BosonSubspaceProjection is preferred when the condensate orbital is known because it removes that direction before diagonalization. This policy does not implement a self-consistent finite-temperature condensate/noncondensate evolution scheme.

Main.Phundamental.Observables.SpectrumConvention — Type
SpectrumConvention(; fourier_normalization=:sqrtN, spectral_axis=:energy, hbar=1.0, kB=1.0)

Conventions used by spectral observables.

fourier_normalization controls the amplitude in O_q = a_N sum_j exp(-i q.r_j) O_j with :sqrtN => a_N=1/sqrt(N), :N => a_N=1/N, and :none => a_N=1. The dynamic structure factor therefore scales as abs2(a_N).

spectral_axis is either :energy (line positions E_n-E_m) or :omega (line positions (E_n-E_m)/hbar). Broadenings use the same units as the selected axis and are normalized to unit integral on that axis.

kB must be expressed in energy units per kelvin if temperature is supplied in kelvin. For meV, a useful value is approximately 0.08617333262 meV/K.

Main.Phundamental.Observables.registered_momentum_field — Function
registered_momentum_field(model, keys; sites=nothing, normalization=:sqrtN)

Construct a MomentumField from observable-registry keys and positions retained by model. When sites=nothing, keys must contain one entry for every model position. Main.Phundamental.Observables.DynamicalCorrelationRequest — Type
DynamicalCorrelationRequest(field, qgrid, axis; ...)
DynamicalCorrelationRequest(field_a, field_b, qgrid, axis; ...)

Describe an intrinsic ordered dynamical correlation S_AB(q,x) for ForwardProblem. The one-field constructor requests the same-field correlation built from field at q and -q. The two-field constructor requests the cross-correlation between independent momentum fields A and B; no adjoint or conjugation is inserted automatically.

The request remains representation-safe when its MomentumFields use registered observable keys because those observables are transformed with the ManyBodyModel. Numerical line broadening is intrinsic to the request and remains separate from probe contraction and instrument resolution.

Main.Phundamental.Observables.CompositeDynamicalCorrelationRequest — Type
CompositeDynamicalCorrelationRequest(fields, qgrid, axis; ...)

Describe the complete ordered dynamical-response matrix for a labeled NamedTuple of MomentumFields. The result contains S_AB(q,x) for every ordered pair of named channels and is returned as a CompositeSpectrumResult. This is the generic high-level request for arbitrary coupled/composite observables; it does not assume any particular physical sector or coupling mechanism.

Main.Phundamental.Observables.SpinPhononCorrelationRequest — Type
SpinPhononCorrelationRequest(qgrid, axis; spin_components=(:x, :y, :z), sites=nothing, spin_prefix=:spin, displacement_prefix=:auto, ...)

Describe a high-level coupled spin-phonon response. At evaluation time the request resolves registered local spin observables and local phonon-displacement observables from the current ManyBodyModel, constructs representation-safe momentum fields, and returns the complete ordered response matrix spanning the selected spin components and the displacement channel.

displacement_prefix=:auto accepts exactly one complete registered family named either boson_displacement_i or phonon_displacement_i on the selected sites. Supply an explicit prefix when both families are present or when a custom registry convention is used.

thermal_probabilities(result; temperature=0, kB=1, degeneracy_tol=1e-10)

Main.Phundamental.Observables.correlation_function — Function
correlation_function(model, result, A, B, times; ...)

Calculate

C_AB(t) = Tr[rho A(t) B(0)]

from the Lehmann representation. For a Hermitian system this is

sum_m p_m sum_n exp[-i(E_n-E_m)t/hbar] A_mn B_nm.

For similarity-transformed/biorthogonal results, left/right matrix elements are used consistently. This routine assumes an effectively real spectrum.

source
Main.Phundamental.Observables.lehmann_lines — Function
lehmann_lines(model, result, A, B; ...)

Return the discrete transitions for

S_AB(x) = sum_mn p_m A_mn B_nm delta(x - x_nm),

where x_nm = E_n-E_m for spectral_axis=:energy and x_nm=(E_n-E_m)/hbar for :omega.

This convention satisfies integral dx S_AB(x) = <A B> before finite-grid windowing. For B=A^dagger in a Hermitian theory the weights are nonnegative up to floating-point error.

source
lehmann_lines(model, result::QuadraticModeResult, A, B; ...)

Return exact Gaussian Lehmann lines generated by bosonic observables of degree at most two in the source operators. Affine-linear observables generate one-quasiparticle lines, while quadratic observables additionally generate elastic, thermal scattering, and two-quasiparticle creation/annihilation channels. The calculation acts directly in mode space and constructs no truncated many-body Fock basis.

source

broaden_lines(lines, axis, broadening)

Numerically represent the intrinsic delta-function spectrum with a normalized line-shape kernel. This is spectral line broadening, not instrument resolution. Instrument response is applied separately by convolve_resolution.

Main.Phundamental.Observables.dynamical_correlation — Function
dynamical_correlation(model, result, field, qgrid, axis; ...)
dynamical_correlation(model, result, field_a, field_b, qgrid, axis; ...)

Compute the ordered momentum-resolved correlation spectrum

S_AB(q,x) = sum_mn p_m <m|A_q|n><n|B_-q|m> delta(x - x_nm),

where x_nm=E_n-E_m for spectral_axis=:energy and x_nm=(E_n-E_m)/hbar for spectral_axis=:omega. The one-field method is the same-field convenience form and uses the same MomentumField for both operators. The two-field method treats field_a and field_b independently and inserts no adjoint or conjugation automatically. Both fields must use the same Fourier-normalization convention.

For spectral_axis=:energy, the stored Lehmann lines are normalized so their integral over energy is <A_q B_-q>. For spectral_axis=:omega, the corresponding angular-frequency convention is used. The returned SpectrumResult is an intrinsic response before any probe contraction or instrument resolution.

source
dynamical_correlation(model, result::QuadraticModeResult, field, qgrid, axis; ...)
dynamical_correlation(model, result::QuadraticModeResult, field_a, field_b, qgrid, axis; ...)

Compute the same ordered S_AB(q,x) directly from a Gaussian bosonic QuadraticModeResult. Each momentum field may be affine-linear or quadratic in the source bosons. The mode-native contraction includes one-quasiparticle, thermal scattering, and two-quasiparticle channels required by the operator order without constructing a truncated many-body Fock basis.

source
Main.Phundamental.Observables.composite_dynamical_correlation — Function
composite_dynamical_correlation(model, result, fields, qgrid, axis; ...)

Compute the complete ordered dynamical-correlation matrix for a labeled NamedTuple of MomentumFields. If the channels are (A=field_a, B=field_b, ...), the returned CompositeSpectrumResult.intensity is indexed (iq, ix, a, b) and stores S_{ab}(q,x) for every ordered channel pair. No Hermitian, reciprocal, or detailed-balance relation is imposed between matrix entries.

All fields must use the same Fourier normalization. The result remains intrinsic: probe contraction and instrument resolution are separate stages.

composite_dynamical_correlation(model, result::QuadraticModeResult, fields, qgrid, axis; ...)

Compute the complete ordered channel matrix directly from a Gaussian bosonic mode solution. The same channel and ordering conventions as the generic solver-result method apply, including explicit handling of the selected bosonic zero-mode policy.

source
spin_tensor_structure_factor(model, result::SpinWaveResult, field, qgrid, axis; ...)

Compute the native Cartesian spin-wave tensor S^{αβ}(q,x) for the current collinear LinearSpinWaveSolver regime. The calculation uses the Bogoliubov mode vectors stored in SpinWaveResult directly and therefore does not build a many-body basis or symbolic Holstein-Primakoff scattering operators.

For a reference sign ηᵢ = ±1, the laboratory-frame operators retained are

Sᵢˣ = sqrt(mᵢ/2) (aᵢ + aᵢ†),
Sᵢʸ = -i ηᵢ sqrt(mᵢ/2) (aᵢ - aᵢ†),
Sᵢᶻ = ηᵢ (Sᵢ - aᵢ†aᵢ),

where mᵢ = Sᵢ - ΔSᵢ by default. This ordered-moment transverse renormalization reproduces the noninteracting spin-wave neutron intensity and sum-rule convention used by Huberman et al. for Rb₂MnF₄. Set renormalize_transverse=false for the strict leading-order Holstein-Primakoff factor sqrt(Sᵢ/2).

The returned tensor contains the requested channels from :elastic, :one_magnon, and :two_magnon. At zero temperature, :two_magnon is the longitudinal pair-creation continuum. At finite temperature it additionally contains pair-annihilation and one-magnon-in/one-magnon-out longitudinal scattering. Mixed transverse-longitudinal components vanish at this Gaussian collinear order.

source

Cartesian spin tensor for a generalized finite-cell SU(2) spin-wave solution.

The elastic and one-magnon sectors are supported. The connected two-magnon longitudinal sector is not implemented and is rejected explicitly. Regulated Goldstone modes are not used to claim certified scattering intensities.

source

Bloch-cell elastic basis form factor and one-magnon spin tensor for both spin-wave formalisms.

The qgrid must match the previously solved Bloch momenta exactly within numerical tolerance. Interactions use physical bond displacements in cis(q⋅δ), so Bloch eigenvectors are in the position-phase gauge: do not apply basis-site Fourier phases a second time to one-magnon amplitudes. The elastic channel is a magnetic-cell basis factor; reciprocal-lattice Bragg delta functions are not constructed. This is a harmonic, single-cell-normalized response, not finite-sample absolute intensity.

source
Main.Phundamental.Observables.static_structure_factor — Function
static_structure_factor(model, result, field, qgrid; ...)

Calculate the equal-time quantity

S(q) = < O_q O_-q >

with the same Fourier normalization used by the dynamic structure factor. For the normalization adopted here it also equals the full-axis integral of S(q,x) before finite-window loss and line-broadening discretization errors.

source
static_structure_factor(model, result::QuadraticModeResult, field, qgrid; ...)

Calculate S(q) = <O_q O_-q> directly from a quadratic bosonic mode result. Momentum-field operators may be affine-linear or quadratic in the source bosons. The static result is obtained by summing the exact unbroadened Gaussian Lehmann weights, so it closes the dynamic/static sum rule before finite spectral-window and discretization effects.

source
static_structure_factor(ensemble, qgrid; positions=nothing,
                          normalization=:sqrtN, connected=false)

Scalar Ising equal-time structure factor

S(q) = < |a_N sum_i s_i exp(-iq.r_i)|^2 >.

With connected=true, the elastic/disconnected contribution |<S(q)>|^2 is subtracted.

Main.Phundamental.Observables.spectral_function_from_retarded_green — Function
spectral_function_from_retarded_green(axis, values; ...)
spectral_function_from_retarded_green(qgrid, axis, values; ...)

Convert a scalar retarded Green function into a real-frequency spectral function. The local form accepts one complex value per spectral point. The momentum-resolved form accepts a matrix indexed (iq, ix).

For normalization=:spectral_density or :minus_im_over_pi, the conversion is A = -Im(G^R)/pi. normalization=:senechal returns the -2 Im(G^R) convention used by the CPT benchmark API. This operation requires retarded real-frequency data; Matsubara data must be analytically continued before calling this function.

source
Main.Phundamental.Observables.commutator_spectral_density — Function
commutator_spectral_density(result::SusceptibilityResult; convention=..., hermitian_channel=nothing)

Convert a scalar Hermitian retarded susceptibility into its commutator spectral density. With the package Fourier conventions, rho_AB(x) = -s Im(chi^R_AB(x))/pi, where s=1 on an energy-transfer axis and s=hbar on an angular-frequency axis.

The input axis must already be real. The function intentionally rejects Matsubara susceptibilities because analytic continuation is a separate, method-dependent operation.

source
Main.Phundamental.Observables.correlation_spectrum_from_retarded_susceptibility — Function
correlation_spectrum_from_retarded_susceptibility(result; temperature, convention=..., hermitian_channel=nothing, zero_frequency_value=nothing)

Convert a scalar Hermitian retarded susceptibility into the ordered equilibrium correlation spectrum S_AB using the fluctuation-dissipation relation. In the package normalization,

S_AB(x) = rho_AB(x) / (1 - exp(-beta*x_E)),

where x_E=x for an energy axis and x_E=hbar*x for an angular-frequency axis. rho_AB is the commutator spectral density returned by commutator_spectral_density.

The input must already be a real-frequency retarded susceptibility. Analytic continuation from Matsubara frequencies is deliberately not performed implicitly. At exactly zero transfer the Bose factor requires a limiting procedure; provide zero_frequency_value explicitly when the requested grid contains zero.

source
Main.Phundamental.Observables.cluster_perturbation_spectral_function — Function
cluster_perturbation_spectral_function(workspace, momenta, axis; eta, t_intercluster, ...)

Evaluate the spin-resolved one-particle spectral function of a one-dimensional cluster perturbation theory reconstruction. The default normalization is -Im G/pi, which integrates to unity per spin and momentum when the complete frequency axis is retained. Set normalization=:senechal to reproduce the -2 Im G convention used by Senechal et al.; set krylov_dim to evaluate a shorter prefix of the projected-Lanczos chains already stored in the workspace.

Main.Phundamental.Observables.detailed_balance_residual — Function

Check the thermal detailed-balance relation for an autocorrelation spectrum:
